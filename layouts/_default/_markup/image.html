{{- $url := .Destination | safeURL -}} {{- $alt := .Text -}} {{- $width := "" -}} {{- $height := "" -}} {{- /* Verifica se a URL contém instrução de tamanho do Obsidian (ex: imagem.png|300x200) */ -}} {{- if strings.Contains $url "|" -}} {{- $parts := split $url "|" -}} {{- $url = index $parts 0 | safeURL -}} {{- $size := index $parts 1 -}} {{- /* Verifica se é largura x altura (ex: 300x200) */ -}} {{- if strings.Contains $size "x" -}} {{- $dim := split $size "x" -}} {{- $width = index $dim 0 -}} {{- $height = index $dim 1 -}} {{- else -}} {{- /* É apenas largura (ex: 300) */ -}} {{- $width = $size -}} {{- end -}} {{- end -}}
